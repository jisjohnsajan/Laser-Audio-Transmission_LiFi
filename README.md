# Laser-Audio-Transmission_LiFi
🔊 Laser Audio Transmission – A low-cost, open-source demonstration of wireless audio communication using modulated laser light instead of radio waves.

This project transmits sound by varying the intensity of a 650nm red laser in sync with an audio signal. At the receiver, a 6V solar panel acts as a photodetector, converting the flickering light back into electrical audio, which is then amplified and played through a speaker.

✅ Zero RF interference
✅ Line-of-sight security
✅ Built for under ₹850 using off-the-shelf components
✅ Educational showcase of amplitude modulation, photovoltaic conversion, and Li-Fi principles

Ideal for physics labs, STEM demos, or anyone curious about free-space optical communication!
